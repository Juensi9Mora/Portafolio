# Portafolio Web — Juensi Carolayn Mora

Portafolio personal y profesional como **Desarrolladora Full Stack Java**, diseñado para presentar mi trayectoria, habilidades técnicas y de comportamiento, proyectos personales y colaborativos, artículos técnicos y canales de contacto.

## ✨ Características y Secciones

* **Inicio:** Presentación principal, propuesta de valor como Desarrolladora Full Stack Java, ubicación, acceso rápido a redes/repositorios (GitHub, LinkedIn, Stack Overflow) y bloque interactivo de código.
* **Acerca de mí:** Historia de crecimiento en el desarrollo de software, motivación por construir soluciones escalables y objetivos profesionales.
* **CV y Stack:** Formación académica y certificaciones (Generation Colombia Cohorte 14, SENA ADSO, rutas complementarias), experiencia práctica en proyectos, stack tecnológico (Java, Spring Boot, MySQL, JavaScript, HTML5, CSS3, Bootstrap, Git/GitHub, Figma) y habilidades blandas.
* **Portafolio de Proyectos:** Filtrado por tipo (*Todos*, *Colaborativos*, *Personales*) con propósito, contribución específica, retos resueltos, tecnologías utilizadas, enlaces al código fuente y modal de detalles para proyectos como **Mi Cancha**, **TrendyShop**, **Compañeros de Vida** y **Planificador de Tareas**.
* **Blog Técnico:** Artículos breves y lectura en modal sobre arquitectura MVC en Spring Boot, flujo de trabajo con Git/Scrum y bases de datos en MySQL.
* **Contacto:** Terminal ilustrativa con flujo Git y formulario con validación de campos y formato de correo.

## 🛠️ Tecnologías Utilizadas

* **Estructura y Estilos:** HTML5, CSS3 (variables CSS, Flexbox, Grid, diseño responsivo y media queries).
* **Interactividad:** JavaScript (manipulación del DOM, filtrado dinámico, modales y validación de formularios).
* **Iconografía y Tipografía:** Boxicons, Devicons y Google Fonts (*Poppins* y *Fira Code*).
* **Control de Versiones:** Git y GitHub.
